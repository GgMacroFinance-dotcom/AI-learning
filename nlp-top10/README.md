# NLP 十大核心算法学习规划

这个目录是一份面向实战的 NLP 学习路线：先用通俗语言理解算法，再把每个算法拆成适合 Codex 生成实现项目的 `goal` 与 `plan`，最后用一个静态可视化网站把十大算法串成一张学习地图。

> 适合人群：已经会基本 Python，希望系统学习自然语言处理，并通过一个个小项目把算法真正写出来的人。

## 你将获得什么

- 一条从传统 NLP 到 Transformer 的学习路线。
- 十大核心算法的通俗理解、使用场景、输入输出和易错点。
- 每个算法一个可交给 Codex 的实现项目规划。
- 一个无需后端、可直接打开的可视化学习网站。

| 阶段 | 时间 | 重点 | 输出物 |

## 1. N-gram 语言模型

### 通俗理解

N-gram 的核心想法是：**一句话里，下一个词大概率和前面几个词有关**。例如看到“我今天想喝一杯”，后面更可能是“咖啡”“奶茶”，而不是“火箭”。N-gram 不试图理解整篇文章，只记住最近的 `n-1` 个词，然后统计下一个词最常出现什么。

### 它解决什么问题

- 估计一句话是否自然。
- 给输入法或自动补全提供候选词。
- 作为理解语言模型、平滑、困惑度的第一课。

### 学习重点

- Unigram、Bigram、Trigram。
- 条件概率 `P(w_i | w_{i-n+1}, ..., w_{i-1})`。
- 平滑：避免没见过的词组概率为 0。
- 困惑度 Perplexity：衡量模型对测试文本的“意外程度”。

### 易错点

不要把 N-gram 当成真正理解语义的模型。它主要依赖局部统计，所以对长距离依赖很弱。

---

## 2. TF-IDF / BM25

### 通俗理解

TF-IDF 像是在问两个问题：这个词在当前文章里出现得多吗？这个词在所有文章里稀有吗？如果一个词在本篇文章中很常见，但在其他文章里不常见，它就更能代表这篇文章。BM25 是搜索系统里更常用的改进版，会考虑文档长度和词频饱和。

### 它解决什么问题

- 搜索引擎的第一版排序。
- 文档相似度计算。
- 关键词提取和候选召回。

### 学习重点

- 词频 TF、逆文档频率 IDF。
- 余弦相似度。
- BM25 的文档长度归一化和词频饱和。
- 倒排索引：从词快速找到包含它的文档。

### 易错点

TF-IDF 和 BM25 不理解同义词。例如“汽车”和“轿车”语义接近，但如果词面不同，传统词袋方法通常无法自然识别。

---

## 3. 朴素贝叶斯

### 通俗理解

朴素贝叶斯像一个经验丰富的分类员：看到“免费、中奖、点击领取”，就判断这封邮件更像垃圾邮件。它“朴素”的地方在于假设每个词相互独立，虽然这个假设并不真实，但在很多文本分类任务上简单有效。

### 它解决什么问题

- 垃圾邮件识别。
- 情感分类。
- 新闻主题分类。

### 学习重点

- 贝叶斯公式。
- 先验概率、似然概率、后验概率。
- 拉普拉斯平滑。
- 多项式朴素贝叶斯与伯努利朴素贝叶斯。

### 易错点

训练和预测时通常要使用 log 概率，否则很多很小的概率连乘会发生数值下溢。

---

## 4. HMM + Viterbi

### 通俗理解

HMM 可以理解为“台前词语 + 幕后状态”。比如做词性标注时，我们能看到单词，但看不到它真正的词性。HMM 假设幕后状态会按一定概率跳转，每个状态又会按一定概率生成词。Viterbi 算法负责在众多可能路径中找出概率最高的状态序列。

### 它解决什么问题

- 中文分词。
- 词性标注。
- 命名实体识别入门。

### 学习重点

- 初始概率、转移概率、发射概率。
- 马尔可夫假设。
- Viterbi 动态规划。
- 序列标注的评估方式。

### 易错点

HMM 的特征表达能力有限。它主要依赖状态转移和词发射概率，无法方便加入丰富上下文特征。

---

## 5. CRF

### 通俗理解

CRF 和 HMM 都在做“给整句话找一条最合理的标签路径”。不同的是，CRF 更像一个阅卷老师：它可以同时参考当前词、前后词、词形、是否大写、是否包含数字等各种线索，然后给整条标签序列打分。

### 它解决什么问题

- 命名实体识别。
- 中文分词。
- 对话系统里的槽位识别。

### 学习重点

- 判别式模型与生成式模型差异。
- 特征模板。
- 转移特征和状态特征。
- 序列级归一化。

### 易错点

CRF 强在特征工程。如果特征模板设计很弱，CRF 的表现也会受限。

---

## 6. Word2Vec

### 通俗理解

Word2Vec 的想法是“看一个词身边经常出现谁，就能猜出它的意思”。如果“国王”和“女王”经常出现在相似上下文里，它们的向量就会靠近。词向量把离散的词变成连续空间中的点，让模型可以计算相似度和语义关系。

### 它解决什么问题

- 词语相似度。
- 文本分类的初始化表示。
- 推荐和检索中的语义特征。

### 学习重点

- CBOW 与 Skip-gram。
- 负采样 Negative Sampling。
- 上下文窗口。
- 最近邻词查询和向量类比。

### 易错点

词向量不是万能语义理解。一个词只有一个静态向量时，很难处理一词多义。例如“苹果”可能是水果，也可能是公司。

---

## 7. TextCNN

### 通俗理解

TextCNN 像拿不同长度的小尺子在句子上滑动，专门寻找有用短语。例如情感分类中，“非常好”“太糟糕”“不太满意”这些局部短语就很关键。卷积核负责捕捉局部模式，池化负责留下最强信号。

### 它解决什么问题

- 情感分类。
- 意图识别。
- 短文本分类。

### 学习重点

- 词嵌入层。
- 一维卷积。
- 多窗口卷积核，例如 2、3、4 个词。
- Max pooling。

### 易错点

TextCNN 擅长抓局部短语，但不擅长建模长距离依赖。

---

## 8. RNN / LSTM / GRU

### 通俗理解

RNN 像一个边读边记笔记的人，每读一个词就更新一次记忆。普通 RNN 记忆容易衰减，LSTM 和 GRU 加入了“门控机制”，决定什么信息该记住、该忘掉、该输出。

### 它解决什么问题

- 序列分类。
- 文本生成。
- 序列标注。

### 学习重点

- 隐状态 hidden state。
- 梯度消失与梯度爆炸。
- LSTM 的输入门、遗忘门、输出门。
- 双向 RNN。

### 易错点

RNN 顺序计算，长文本训练慢；即使用 LSTM/GRU，也不代表可以轻松处理所有长距离依赖。

---

## 9. Seq2Seq + Attention

### 通俗理解

Seq2Seq 是“读入一段话，再生成另一段话”。Encoder 负责读懂输入，Decoder 负责输出目标文本。Attention 的作用像翻译时边写边回看原文重点，不再要求模型把整句话全部压进一个固定长度向量。

### 它解决什么问题

- 机器翻译。
- 文本摘要。
- 问答和对话生成。

### 学习重点

- Encoder-Decoder 架构。
- Teacher forcing。
- 注意力权重。
- Beam search。

### 易错点

Seq2Seq 生成任务评估很复杂。训练 loss 下降不一定代表输出质量好，需要结合 BLEU、ROUGE 或人工样例检查。

---

## 10. Transformer / BERT / GPT

### 通俗理解

Transformer 把“逐词读句子”改成“每个词直接看全句所有词”。Self-Attention 会计算词与词之间的关系，判断谁该关注谁。BERT 更偏理解，常用于分类、抽取、匹配；GPT 更偏生成，常用于续写、对话、代码和任务型生成。

### 它解决什么问题

- 文本分类、实体抽取、问答、摘要、翻译、生成。
- 大模型微调与指令应用。
- 检索增强生成 RAG 的基础组件。

### 学习重点

- Self-Attention、Multi-Head Attention。
- 位置编码。
- Encoder 与 Decoder。
- 预训练、微调、提示词和上下文学习。

### 易错点

Transformer 不是只靠模型结构强大，数据规模、训练目标、算力、清洗质量和评估体系都很关键。

## 如何使用可视化网站

直接在浏览器打开：

```text
nlp-top10/site/index.html
```

或者用本地静态服务器打开：

```bash
cd nlp-top10/site
python -m http.server 8000
```

然后访问本地页面即可。网站会把十大算法按学习阶段、任务类型、难度和算法关系可视化展示。

## 建议学习方法

1. 每学一个算法，先用自己的话复述“它在解决什么问题”。
2. 再看公式或代码，避免一开始陷入细节。
3. 每个算法都完成一个最小可运行项目。
4. 每个项目至少包含：数据样例、训练或索引脚本、推理脚本、README、单元测试。
5. 学完十个算法后，做一个综合项目：用 BM25 做召回，用 Transformer 或 BERT 做重排/理解，用可视化页面展示结果。

## 最终综合项目建议

**项目名：NLP Algorithm Explorer**

目标：把十大算法串成一个交互式学习系统。

核心功能：

- 点击算法卡片查看：通俗解释、输入输出、适合任务、复杂度。
- 根据任务类型筛选算法：分类、检索、序列标注、生成、表示学习。
- 用学习路径视图展示算法演进：统计方法 → 序列模型 → 神经网络 → 注意力 → Transformer。
- 给每个算法附一个 Codex 实现任务入口。

这份路线不追求一次性“背完 NLP”，而是通过十个能跑起来的小项目，建立从词袋统计到大模型架构的完整心智模型。
